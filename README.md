# 📊 Calculadora de Média (Python + Tkinter)

Um projeto simples que fiz para praticar a criação de interfaces gráficas em Python usando a biblioteca **Tkinter**.

O programa recebe 4 notas de um aluno, calcula a média e mostra se ele foi **Aprovado** ou **Reprovado**.

---

## 🎯 O que o projeto faz?

- Permite digitar 4 notas numa tela simples.
- Calcula a média ao clicar no botão.
- Mostra "Aprovado" para média 5.0 ou superior, e "Reprovado" para notas menores.
- Exibe um aviso amigável se forem digitados caracteres inválidos ou letras.

---

## 🧠 O que pratiquei aqui?

- Criar janelas, botões e campos de texto com Tkinter.
- Organizar os elementos na tela com `.pack()`.
- Converter textos de entrada em números (`float`).
- Usar `try/except` para tratar erros e `messagebox` para avisos.
